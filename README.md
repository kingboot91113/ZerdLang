# ZerdLang

## Örnekler

`examples/hello.zd`, ZerdLang manifestosundan ilham alan kısa bir ZerdCore programıdır.

### Çalıştırma

```bash
# Depo kökünden çalıştırın
zerdcore run examples/hello.zd
```

Alternatif olarak CLI farklıysa aşağıdaki şablonu kullanabilirsiniz:

```bash
<zerdcore-komutu> run examples/hello.zd
```
